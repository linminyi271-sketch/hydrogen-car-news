# 零排放車產業新聞

本網站沿用「機器人產業新聞週報」原始網站的版型與功能，整合氫能車及純電動車產業新聞。

## 已包含功能

- 依週別瀏覽：上一期／下一期、期別選單、歷史期別清單
- 本週重點觀察：顯示、編輯、儲存；可複製含本期新聞的 AI 撰寫指令
- 跨期全文搜尋，並依區域、來源媒體、主題標籤篩選
- 上傳單一 Word（.docx）週報，同時解析氫能車／純電動車及亞洲／國際四個分類，建議標籤、略過重複新聞
- 貼上文字／JSON 解析，或手動單則新增
- 匯出 PDF（目前期別與篩選結果）、CSV（目前顯示新聞）、CSV（全部期別）
- 深色模式、響應式手機版
- 後端可記錄上傳者與上傳時間；前台不顯示上傳者

## 預覽模式與共用資料庫

目前 `config.js` 的 `API_URL` 留空，網站以預覽模式啟動。搜尋、篩選、期別瀏覽、Word 解析、重點觀察編輯及匯出等前端功能可使用；新增或編輯資料只儲存在目前瀏覽器，不會自動同步給其他使用者。

若要讓團隊共用新聞、儲存重點觀察及記錄上傳者，請依 `SETUP.md` 建立 Google 試算表並部署 `apps-script/Code.gs`，再將部署網址填入 `config.js` 的 `API_URL`。刪除操作也會寫入後端，以隱藏標記保留紀錄。

## 每週上傳格式

每週只需準備一份 Word（.docx），建議依序使用以下四個標題；沒有新聞的區塊可以省略：

- `【氫能車｜亞洲新聞】`
- `【氫能車｜國際新聞】`
- `【純電動車｜亞洲新聞】`
- `【純電動車｜國際新聞】`

每則新聞沿用原格式：`新聞標題 - 來源媒體 YYYY/MM/DD`，下一段放摘要，再下一行放 `原文連結：https://...`。若車種無法從區塊或標題判斷，預覽畫面會要求手動選擇，不會直接讓未分類新聞發布。

## 舊資料庫升級

若原本已連接 Google 試算表，請將新版 `apps-script/Code.gs` 貼回原 Apps Script 專案並儲存，再執行一次 `setup`（會在既有 `news` 分頁最右側補上 `vehicle_type` 欄，不會刪除舊資料），最後到「部署 → 管理部署作業 → 編輯 → 新版本 → 部署」。網站原有 API 網址不需更換。

## 檔案結構

- `index.html`：頁面結構
- `config.js`：網站名稱、車種、區域、主題標籤與資料庫設定
- `assets/style.css`：版型與樣式
- `assets/app.js`：搜尋、篩選、匯出、上傳及互動功能
- `assets/parser.js`：Word／文字解析
- `assets/store.js`：資料讀寫
- `assets/vendor/jszip.min.js`：Word 解析所需套件
- `data/seed.js`：預覽模式新聞與重點觀察
- `apps-script/Code.gs`：Google 試算表後端
- `SETUP.md`：共用資料庫部署說明
