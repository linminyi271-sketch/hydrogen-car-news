# 氫能車產業新聞

本網站沿用「機器人產業新聞週報」原始網站的版型與功能，新聞主題改為氫能車產業。

## 已包含功能

- 依週別瀏覽：上一期／下一期、期別選單、歷史期別清單
- 本週重點觀察：顯示、編輯、儲存；可複製含本期新聞的 AI 撰寫指令
- 跨期全文搜尋，並依區域、來源媒體、主題標籤篩選
- 上傳 Word（.docx）週報，自動解析新聞、建議標籤、略過重複新聞
- 貼上文字／JSON 解析，或手動單則新增
- 匯出 PDF（目前期別與篩選結果）、CSV（目前顯示新聞）、CSV（全部期別）
- 深色模式、響應式手機版
- 後端可記錄上傳者與上傳時間；前台不顯示上傳者

## 目前資料

- 週報期間：2026/10/26–11/01
- 10 則新聞：亞洲 3 則、國際 7 則
- 已附本週重點觀察

## 預覽模式與共用資料庫

目前 `config.js` 的 `API_URL` 留空，網站以預覽模式啟動。搜尋、篩選、期別瀏覽、Word 解析、重點觀察編輯及匯出等前端功能可使用；新增或編輯資料只儲存在目前瀏覽器，不會自動同步給其他使用者。

若要讓團隊共用新聞、儲存重點觀察及記錄上傳者，請依 `SETUP.md` 建立 Google 試算表並部署 `apps-script/Code.gs`，再將部署網址填入 `config.js` 的 `API_URL`。

## 檔案結構

- `index.html`：頁面結構
- `config.js`：網站名稱、區域、主題標籤與資料庫設定
- `assets/style.css`：版型與樣式
- `assets/app.js`：搜尋、篩選、匯出、上傳及互動功能
- `assets/parser.js`：Word／文字解析
- `assets/store.js`：資料讀寫
- `assets/vendor/jszip.min.js`：Word 解析所需套件
- `data/seed.js`：預覽模式新聞與重點觀察
- `apps-script/Code.gs`：Google 試算表後端
- `SETUP.md`：共用資料庫部署說明
